# Evidencias de entrega de Kippu

Guarde las capturas en `documentacion/evidencias/capturas/` con los nombres indicados. No incluya números completos de tarjeta, contraseñas, claves ni archivos `.env`.

| Archivo | Evidencia |
|---|---|
| `01_admin_locales_mesas.png` | Local, mesa y botón para descargar QR |
| `02_qr_carta_telefono.png` | Carta abierta desde un teléfono |
| `03_carrito_opciones.png` | Cantidades, opciones y recargos |
| `04_propina_mayoria_edad.png` | Propina y confirmación para productos +18 |
| `05_webpay_integracion.png` | Pantalla de integración sin datos sensibles |
| `06_comprobante.png` | Pago autorizado y desglose |
| `07_cocina.png` | Pedido pagado pendiente o en preparación |
| `08_entregas.png` | Pedido listo para entregar |
| `09_caja_cierre.png` | Cuenta y cierre de mesa |
| `10_pruebas_postgresql.png` | Suite ejecutada en PostgreSQL |
| `11_docker_segundo_pc.png` | Sistema iniciado con Compose |
| `12_commits_equipo.png` | Historial visible de ambos integrantes |

Cada captura debe ir acompañada por una frase que indique qué requisito demuestra. El registro automático disponible no sustituye las capturas de PostgreSQL, Docker o Webpay real de integración.
